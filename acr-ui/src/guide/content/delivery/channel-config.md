# 通知渠道配置

这篇帮你创建钉钉/企微/飞书群机器人渠道、在平台配置并测试，最后绑定到项目。

## 第 1 步：在 IM 端创建群机器人

### 钉钉

1. 打开目标群 → 群设置 → **智能群助手** → **添加机器人** → 选择 **自定义**（通过 Webhook 接入）；
2. 机器人名称填 `ACR 审查通知` 之类可识别名称；
3. 安全设置三选一（可多选）：
   - **加签**（推荐）：记录生成的加签密钥；
   - **自定义关键词**：关键词必须包含平台消息一定会出现的词，建议填 `AI Code Review`（详见「投递与通知 → 投递失败排查」）；
   - IP 地址（段）：需把平台部署服务器的出口 IP 加入；
4. 完成后复制机器人的 Webhook 地址（形如 `https://oapi.dingtalk.com/robot/send?access_token=xxxx…`）。

### 企业微信

1. 打开目标群聊 → 右上角 `···` → **群机器人** → 添加机器人；
2. 名称填 `ACR 审查通知`，创建后复制 Webhook 地址（形如 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxx…`）；
3. 企微群机器人无加签等附加安全设置，地址中的 key 即凭据，注意不要外泄。

### 飞书

1. 打开目标群 → 群设置 → **群机器人** → **添加机器人** → 选择 **自定义机器人**；
2. 名称填 `ACR 审查通知`；
3. 安全设置按需开启：签名校验（记录密钥）或 IP 白名单；
4. 复制 Webhook 地址（形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxx…`）。

## 第 2 步：在平台新增渠道并测试

进入「通知管理 → 通知渠道」，点击「新增」：

| 字段 | 填写 |
|---|---|
| 渠道名称 | 如 `研发一部-钉钉群` |
| 渠道类型 | 钉钉机器人 / 企微机器人 / 飞书机器人 |
| Webhook URL | 第 1 步复制的机器人 Webhook 地址 |
| 加签 Secret | 钉钉加签密钥或飞书签名密钥；企微或机器人未开签名时留空 |
| 状态 | 启用 |

保存后点击该行「测试」，群里收到标题为「AI Code Review 渠道测试」的消息且列表「检测状态」变为「发送正常」即配置成功。失败时按提示的机器人返回信息处理（见「投递失败排查」）。

## 第 3 步：绑定到项目

进入「项目接入 → 代码项目」，编辑目标项目 → 切换到「通知」页签：

1. **启用通知**：开启；
2. **通知渠道**：选择第 2 步创建的已启用渠道（每个项目只绑定一个渠道；渠道是平台级资产，可被多个项目复用）；
3. **失败时通知**：默认开启——审查执行失败时发送简讯；关闭则仅在审查成功（SUCCESS）时发送摘要；
4. 保存项目。

## 投递内容形态

- 审查成功：结论摘要卡，包含结论（通过/建议修改/高风险）、评分、重点问题、审查范围、总结与平台详情链接；
- 审查执行失败：简讯，包含失败类型与详情链接（需开启「失败时通知」）；
- 企微单条正文超过 4096 字节时自动截断；飞书消息以富文本形式呈现。

## 验证

绑定后发起一个测试 PR 走完一次审查，确认群里收到消息；也可到「通知管理 → 投递记录」查看该任务的投递状态（已投递/投递失败）与失败原因。
