# 投递失败排查

这篇帮你定位「投递记录」中出现投递失败的原因（机器人安全设置、网络出口），并完成补发。

## 第 1 步：读取失败原因

进入「通知管理 → 投递记录」，按项目/PR 编号/时间筛选找到失败记录，查看「失败原因」列。失败原因来自 IM 平台的返回信息，按下面的分类对号入座。

## 钉钉：自定义关键词未命中

钉钉机器人开启「自定义关键词」安全设置时，消息必须包含至少一个关键词才能发送，否则返回「keywords not in content」类错误。

平台发送的所有消息（审查摘要、失败简讯、渠道测试消息）标题都包含 `AI Code Review`。处理方式二选一：

- 在钉钉机器人安全设置中把关键词改为或追加 `AI Code Review`；
- 或改用加签方式（见下条）。

## 钉钉/飞书：加签密钥不一致

机器人开启加签（签名校验）时，平台渠道的「加签 Secret」必须与机器人侧密钥完全一致，否则返回签名错误。

处理：进入「通知管理 → 通知渠道」→ 编辑该渠道，重新从机器人设置页复制密钥填入「加签 Secret」，保存后点「测试」验证。

## 企微：key 失效或机器人被移除

企微返回 key 不存在类错误时，说明机器人被移除或重建导致 Webhook 地址变化。处理：重新创建机器人，更新渠道的 Webhook URL 后点「测试」。

## IP 白名单限制

机器人设置了 IP 白名单时，平台部署服务器的出口 IP 必须在名单内。处理：在机器人安全设置中加入平台出口 IP，或取消白名单限制。

## 内网出站限制

三个 IM 的机器人地址都是公网服务（`oapi.dingtalk.com` / `qyapi.weixin.qq.com` / `open.feishu.cn`）。失败原因显示连接超时/无法连接时，多为内网服务器没有外网出口。处理：申请外网出站或代理；确认出站策略放通上述域名。

## 第 2 步：修复后补发

1. 按上面分类修复原因；
2. 回到「通知管理 → 投递记录」，对失败记录点击「补发」（补发会向原渠道重新发送，群内可能出现重复消息）；
3. 「投递状态」变为「已投递」即完成。

> 提示：「消息详情」按钮可查看该条投递的消息快照；较早的投递记录可能未保留快照，按钮会置灰，属正常现象。
