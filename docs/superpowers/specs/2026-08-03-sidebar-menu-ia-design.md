# 左侧菜单信息架构调整设计

> **状态（2026-08-03）：已确认，待实现。**  
> 范围：仅调整侧栏菜单名称、层级、归属与排序；不新增业务功能；不修改路由业务逻辑、后端接口、权限串与页面代码（工作台侧栏可见性除外）。  
> 前置：`docs/planning/product-roadmap.md` §4；现有 `sys_menu` 增量脚本至 `sql/26_*`；M7 工作台已落地于 `/index`。

## 1. 目标与成功标准

### 1.1 目标

按中度对齐路线图的方式，重组除「系统管理」「系统监控」以外的业务侧栏，使：

- 日常处置、项目接入、策略配置职责分离；
- 一级顺序符合使用频率：行动 → 运营 → 接入 → 策略 → 通知 → 治理运维；
- 原有页面均可经侧栏到达，权限串与组件路径不变。

### 1.2 成功标准

1. 侧栏呈现下文「目标菜单树」；「系统管理」「系统监控」子树与现状完全一致。  
2. 工作台在侧栏可见，点击进入既有 `/index`。  
3. 所有既有业务页（业务系统、代码项目、凭据、模板、模型、引擎、任务、记录、问题、通知渠道、投递记录）均可从新归属进入。  
4. 不新增空能力入口（数据洞察、报告中心、审查方案、规则库等）。  
5. `path` / `component` / `perms` / 接口 / 页面逻辑不变；仅 `menu_name`、`parent_id`、`order_num` 及工作台路由 `hidden` 调整。

## 2. 当前基线

| 顺序 | 一级菜单 | 子菜单 |
|---|---|---|
| — | 工作台（`/index`，父路由 `hidden: true`，侧栏不可见） | 无 |
| 1 | 代码审查（3） | 业务系统管理、项目管理、审查模板、访问凭据、审查任务、审查记录、问题台账 |
| 2 | 通知管理（5） | 通知渠道、投递记录 |
| 3 | 模型服务（4） | 大模型配置、审查引擎（提示词管理已下线） |
| 4 | 系统管理（1） | 用户/角色/菜单/部门/岗位/字典/参数/公告/日志… |
| 5 | 系统监控（2） | 在线用户/定时任务/数据监控/服务监控/缓存… |

主要问题：处置与接入挤在「代码审查」；策略资产（模板/模型/引擎）跨目录；工作台已落地但未出现在侧栏。

## 3. 产品决策

1. **中度对齐路线图**：拆出审查中心、项目接入；模型服务更名为策略配置并收拢模板；纳入工作台；不预建未落地入口。  
2. **配置与处置分离**：审查中心只承载问题/任务/记录；项目接入承载归属与仓库接入；策略配置承载“怎么审”。  
3. **系统管理 / 系统监控整棵子树冻结**，名称、顺序、归属均不改。  
4. **命名偏企业用户习惯**：审查中心、项目接入、策略配置、代码项目、业务系统；避免 Provider/Prompt 等技术词。

### 4.2 排序理由（摘要）

- **审查中心**：行动优先——问题台账 → 审查任务 → 审查记录。  
- **项目接入**：首次接入路径——业务系统 → 访问凭据 → 代码项目。  
- **策略配置**：业务可达性——审查模板 → 大模型配置 → 审查引擎。  
- **一级总序**：工作台 → 审查中心 → 项目接入 → 策略配置 → 通知管理 → 系统管理 → 系统监控。

## 6. 实现边界

### 6.1 允许变更

1. 新增增量 SQL（建议 `sql/27_sidebar_menu_ia.sql`）：  
   - 插入一级目录 `menu_id=6`「项目接入」；  
   - 更新上述 `menu_name` / `parent_id` / `order_num` / remark；  
   - 为已拥有子菜单权限的角色补授 `menu_id=6`（至少 `role_id=2` 与现网一致模式）。  
2. `acr-ui/src/router/index.js`：工作台父路由去掉 `hidden: true`（或等价方式使侧栏展示「工作台」），`path`/`component`/`meta.title` 不变。  
3. 必要时同步 README / 路线图中与旧菜单名不一致的描述句（可选、最小 diff）。

### 6.2 禁止变更

- 任意页面 Vue、API、Controller、Service、权限注解、`perms` 字符串；  
- 业务路由 `path`（如 `review/task`）与 `component`；  
- 系统管理、系统监控任意子项；  
- 预建数据洞察等工作台以外的空一级菜单。

### 6.3 风险与缓解

| 风险 | 缓解 |
|---|---|
| 角色有子菜单无新父目录导致侧栏不显示 | SQL 为相关角色插入 `sys_role_menu`（6） |
| 浏览器缓存旧动态路由 | 重新登录或清 tags-view 后验证 |
| 文档仍写「代码审查」「模型服务」 | 实现时仅改会误导运维的关键句，或单开文档任务 |
